## 重新生成

在项目根目录运行：

```bash
flutter drive --driver=test_driver/screenshots.dart --target=integration_test/app_test.dart -d emulator-5558
```

测试使用独立的演示状态驱动真实界面，结束后截图接收器会保存所有 PNG。真实存储测试会在验证后恢复测试前的数据。
